## Known pitfalls carried over from M0–M3 (do not rediscover them)
- **AGP 9.5.0 / Gradle 9.8.2, built-in Kotlin, new DSL.** No `org.jetbrains.kotlin.android`; `kotlin.plugin.compose` + `kotlin.plugin.serialization` 2.4.21 are applied to `nib-android`. `androidComponents.sdkComponents.ndkDirectory`, `sourceSets.<name>.{jniLibs,kotlin,assets}.directories.add(...)`; fixtures are shared as test assets via `assets.directories.add("../nib-rs/nib-core/tests/fixtures")` (so `form.pdf` is available to instrumentation tests automatically). `compileSdk = 37`, `targetSdk = 36`. Configuration cache on. Debug builds only the host ABI; release `lto = "fat"` ×3 ABIs takes ~15 min — iterate on debug.
- **UniFFI 0.32.2**: bindings come from the host **debug** `libnib_ffi` (`./gradlew :nib-android:uniffiBindgenDebug`, read `nib-android/build/generated/uniffi/debug/uniffi/nib_ffi/nib_ffi.kt` for exact Kotlin types: `u32→UInt`, `u64→ULong`, `Vec<u8>→ByteArray`, errors → `NibException.<Variant>` with `v1`/named fields). Callback interfaces (`AssetProvider`, `FontProvider`) are `#[uniffi::export(with_foreign)]` traits taking `Option<Arc<dyn …>>`; they run synchronously on the calling thread **while the engine mutex is held** — never call back into `NibDocument` from them. Kotlin continuations of async fns resume on the Rust worker thread.
- **Render worker**: one process-wide `RenderWorker` (`OnceLock`); new pdfium features = `Ctrl` messages handled in `renderer.rs`; `Renderer::swap(id, bytes)` is used by `flush` (≤ 2 resident docs via `DocSlot`). `page.boundaries().crop()` errors when `/CropBox` is absent → media box fallback. Pixels are RGBA.
- **Writer facts (M3)**: `Writer { bytes, doc: Option<Document>, page_ids, ids: HashMap<Uuid, ObjectId>, foreign_ap, popups, revision }`; `flush` takes the doc, builds `IncrementalDocument::create_from(bytes, doc.clone())`, saves to `Vec<u8>`, **re-parses** the output with lopdf and only then adopts it (restoring doc + maps on any error); `FullRewrite` = clone → `prune_objects` → `renumber_objects` → object/xref streams (classic fallback with a warning), refused with `SignedDocument` when any `/Sig` with `/ByteRange` exists, and `page_ids`/`ids` are rebuilt from the reparsed doc afterwards. Updates with `appearance.regenerate == false` keep the foreign `/AP` and patch only dict keys. Annotations whose `/Annots` entry is an inline dict (no object id) are imported but cannot be updated in place (an update would create a second annotation) — known limitation. `Engine::flush_ops()` = compacted **annotation** ops; `mark_flushed(rev)` sets `base = model`; `uncommitted_ids()` = base≠model. Lock order in `nib-ffi`: writer → engine. If `worker.swap` fails after a successful write, the engine is not marked flushed and the next flush re-applies the same ops (duplicate creates) — fix if you touch that path.
- **`/AP` facts (M3)**: `ap::build(&Annotation, &dyn AssetSource, &dyn FontSource) -> ApOutput { bbox, content, ext_gstate, fonts, images, warnings }`; content always starts with `/GS0 gs`; form space == user space (`/BBox` = rect, identity `/Matrix`), so every operator including the first `Td` is absolute. PDF default line cap is butt — set `1 J` explicitly where the Compose overlay uses round caps. Base-14 widths live in `ap::fonts` (WinAnsi 32–255; `to_winansi` replaces unencodable chars with `?`). The parity test (`nib-render/tests/ap_parity.rs`) rasterizes text with `swash` + Arial / Liberation Sans / DejaVu from host font dirs — CI installs `fonts-liberation`; without a font it falls back to solid bars (pHash ≈ 18 for FreeText → failure), so keep the apt step. FreeText @ opacity 1 is allowed pHash ≤ 9, everything else ≤ 6.
- **Fixtures**: `gen_fixtures.rs` builds every PDF (`text, vector, image, rotated90, cropbox, text-100, incr-classic, incr-xrefstream, incr-linearized (via qpdf --linearize — lopdf's linearize option is a no-op), incr-presigned, incr-hybrid (byte-assembled /XRefStm), annots-existing, stamp-src.png/.jpg`); regenerate with `cargo test -p nib-core --test gen_fixtures regenerate_fixtures -- --ignored`. `qpdf --check` exits 3 on warnings (accepted) — only 1/2 are failures. `NIB_KEEP_PDFS=<dir> cargo test -p nib-core writer::tests` keeps every checked output for manual reader checks.
- **Delta engine facts**: `Engine::apply(Vec<Op>)` = one undo step, atomic; `create` payloads omit `id`/`page`; `rect` derived via `dirty::bbox` (Ink pad uses `maxWidthFactor` default 1.6 when pressure-sensitive); coalescing on single-key `rect/strokes/value/quadPoints/start/end` < 500 ms — `value` is the form-field typing key; undo of delete re-inserts at the end of `Model.order`; `import` rejects `baseRevision ≠ revision` unless `rebase`. Schema: regenerate with `cargo test -p nib-core --test schema schema_regenerate -- --ignored` if model types change; every fenced JSON block in `docs/JSON_SCHEMA.md` must stay valid.
- **Compose facts**: `NibPdfView` gates scroll/pinch/double-tap on `state.tool == Tool.Pan`; `PageTransform.kt` mirrors `geom/transform.rs`; annotations expose `contentDescription = "annotation:<Subtype>"` + `testTag("annot:<id>")`; tile semantics boxes carry `testTag("tile:p:tx:ty")` + `stateDescription = "revision:N"`. `TileScheduler` re-requests only tiles intersecting `document.dirtyLog` entries newer than their recorded revision and keeps the old bitmap until the new one lands; `paused` is a `@VisibleForTesting` flag; `tileRevision` is a `ConcurrentHashMap` (render coroutines write it while Compose reads). Auto-flush (`FlushPolicy` idle 2 s / 50 ops) is on by default in `rememberNibPdfViewState`; tests use `setUpView(flushPolicy = FlushPolicy(enabled = false))` from `M2TestSupport.kt` — do the same for form tests or the flush will race your assertions. `rule.setContent` is single-use; `activity.setContent` inside the scenario for a second view. `HistoricalChange.pressure` does not exist in Compose 1.12.1.
- **Sample app**: palette row 2 scrolls horizontally; `Save`/`Save As…` chips (`action:save`, `action:saveAs`) are off-screen on a Pixel 6 until scrolled; swipes at x ≥ 1050 trigger system Back; Save writes back to the picked `Uri` with `openOutputStream(uri, "wt")`.
- **Reader quirks seen in M3**: macOS Preview draws its own sticky-note icon regardless of our `/AP` (size differs); Chrome/PDFium and pdf.js honour every `/AP`. Acrobat unavailable on this machine.
- Remote CI (`.github/workflows/ci.yml`) has **never run** — nothing has been pushed. If asked to push, watch the first run (SDK install, emulator boot, cargo-ndk cache key, host PDFium fetch, `apt-get install qpdf fonts-liberation`).
- Emulator `nib_api34` is often still running — `adb devices` first. `ScrollBenchmark` numbers are emulator-only; do not tune for them.
